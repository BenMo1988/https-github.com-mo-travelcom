# Voya – Reisartikelen E-commerce

Strategie- en planningsdocumenten voor een internationaal e-commercemerk in reisartikelen (koffers, crossbody tasjes, rugtassen) en comfortproducten zoals vliegtuigpakketjes en reisorganizers. De webshop draait op Shopify (thema Dawn).

## Inhoud

- `Merkstrategie - Reisartikelen Ecommerce.md` — merkidentiteit, doelgroep en buyer persona's
- `Landingspagina Structuur.md` — opbouw van de landingspagina
- `Productpagina Elementen.md` — productpagina-elementen (o.a. sticky add-to-cart, UGC/reviews)
- `App Shortlist - Sticky Cart en UGC-Reviews.md` — shortlist van Shopify-apps
- `Shopify Abonnement Keuze.md` — afweging Shopify-abonnement
- `Sourcing Template - Taobao BuckyDrop.md` — sourcingtemplate voor leveranciers
- `Voorbeeldproducten - Placeholder.md` — voorbeeldproducten

## Testen

Dit project gebruikt [Playwright](https://playwright.dev/) voor browsertests.

```bash
npm install
npx playwright install
npx playwright test
```
